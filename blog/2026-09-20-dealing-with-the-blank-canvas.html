Dealing with the blank canvas

Why the hardest part of a new brief isn't the work — it's the first ten minutes of nothing, and the small ritual that gets me past it.

A new brief landed this morning. Good client, interesting problem, reasonable deadline. I opened Figma, created the file, named it properly, set up the page structure — and then just sat there, cursor blinking, feeling the particular weight of an empty frame.

I've done this hundreds of times. It doesn't matter. The blank canvas still gets me, every single time, for about ten minutes.

What the ten minutes actually are

For a long time I read that hesitation as a warning: maybe I don't understand the problem well enough, maybe I need more research, maybe I'm the wrong person for it. I've since learned it's none of those things. It's just the brain refusing to commit to a first move when every move is still available. The anxiety isn't about the work. It's about the infinite version of the work — the perfect one that dies the moment you place a single rectangle.

Dealing with it starts with accepting that the perfect version was never real. It only feels real because it hasn't been tested against anything yet.

The ritual that works for me

I don't try to beat the ten minutes anymore. I give them a job:

  • Write the problem in one ugly sentence. Not the brief's language — mine. "The ops team needs to see which deliveries are late before the client calls them." If I can't write that sentence, then I'm allowed to worry about research.
  • Make the worst version on purpose. Grey boxes, wrong labels, comic-sans energy. It takes three minutes and it kills the infinite version immediately, because now there are two options and the bad one is already taken.
  • Set a ten-minute timer. Whatever exists when it rings gets critiqued, not judged. Critique moves things forward. Judgement just makes them heavier.

The point

None of this makes the discomfort disappear, and I don't think it should. The ten minutes are a signal that I care about the outcome. The goal isn't to feel nothing — it's to have a next action ready so the feeling doesn't get a vote on whether I start.
